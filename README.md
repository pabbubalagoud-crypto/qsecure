Q-Secure is an interactive BB84 Quantum Key Distribution simulator that detects eavesdroppers on quantum communication channels in real time.

If anyone intercepts the channel, the laws of physics expose them — causing the Quantum Bit Error Rate (QBER) to spike from 0% → 25%, triggering an immediate alert.

Eve OFF → QBER ≈ 0% → 🟢 Secure
Eve ON → QBER ≈ 25% → 🔴 Eavesdropping Detected
